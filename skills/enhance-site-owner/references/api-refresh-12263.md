# Public API refresh: 2026-11-11

Source: [public OpenAPI](https://apidocs.enhance.com/spec/oas3-api.yaml), 12.26.3, compared to bundled 12.25.8; [release notes](https://enhance.com/support/release-notes) list product 12.26.6. These version numbers do not establish the version or behavior of any live controller.

The resolved schema diff reports 16 new, zero removed, and two changed operations: persistent-app creation and listing. New operations cover GitHub app/repository connections, website deployments, callbacks, Node versions, and member session issuance. `PersistentApp` adds optional `appKind`; `PersistentAppKind` adds `nodejs`, `django`, `tomcat`, `laravel`, and `php`. Existing access-token, role and related component schemas were unchanged in the component comparison; unchanged schema does not prove unchanged live permissions.

Manifest callback replaces stored app credentials; install callback stores an installation ID; the webhook accepts a signed GitHub event that can trigger deployment. The generic runner refuses all three rather than submitting callback secrets or bearer credentials to an unsupported protocol. Git deployment configuration, repository lists/refs, history and logs require explicit apply and private output, and are excluded from ordinary read batches. `createMemberSession` issues a bearer credential treated like a password and requires explicit apply and private output. Do not publish session output. New Git deployment mutations can modify a website and require separate authorization, rollback and verification.

The new snapshot was checked offline with synthetic fixtures only. No current controller version, live compatibility, restricted-principal isolation, write/restore/rollback, GitHub integration or production result was tested. Freshness remains due: the prior review date is retained until the outstanding gates are completed. The older detailed procedures retain their original source baseline; they have not been globally re-reviewed against 12.26.3.
